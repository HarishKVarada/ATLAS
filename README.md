# ATLAS

ATLAS is an AI-assisted market analysis and trading decision-support platform.

The project is intended to combine market data, technical analysis, options
analysis, risk controls, explainable reasoning, and structured trade journaling.

## Current Phase

Phase 0 — Project Foundation

## Current Status

- GitHub repository created
- Repository cloned locally
- Project proposal created
- Day 0 development branch created
- Initial project structure in progress
- Application development not yet started

## Important Rule

ATLAS will initially operate only as a research and decision-support system.

It will not place live trades during the initial development phases.
